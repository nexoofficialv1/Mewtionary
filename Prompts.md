# Prompts and Learning Messages

Mewtionary v2.8 does not use an unrestricted generative-AI chat system.

Content is driven by reviewed JSON/JSONL lesson data, accepted answers,
scoring rules and fixed learning messages.

## Message rules

- Use simple Bangla support with age-appropriate English.
- Never shame a child for an incorrect answer.
- Provide a short correction and a retry opportunity.
- Do not generate unsafe, adult or unrelated content.
- Homework tools should guide structure rather than impersonate the child.
- Speech output must start only after an explicit learning action.
