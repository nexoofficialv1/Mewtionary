# Mock Exam Engine v2.7

Supported question types:
- multiple choice
- fill in the blank
- sentence rearrangement
- short answer

Features:
- class-wise accessible papers
- countdown timer
- previous/next navigation
- automatic submission when time ends
- marks and pass threshold
- skill-wise result
- answer review and explanation
- offline attempt history
- daily duplicate-reward protection

Short-answer checking uses minimum sentence rules or approved answer ideas. A teacher should review high-stakes writing assessments.
