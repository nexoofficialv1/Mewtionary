# Mewtionary Adaptive Learning Engine v2.4

## Placement assessment
The diagnostic module uses questions tagged by class rank and skill. It calculates overall accuracy, strongest solved level and skill-wise accuracy. The recommended level can be applied to the student's profile.

This is an educational placement aid, not a certified psychological or academic examination.

## Daily plan
The daily plan uses:
- saved student level
- lesson prerequisites
- incomplete next lesson
- due revision
- parent-selected daily time limit

It then fills the available time with lesson, dictionary, voice and writing tasks.

## Pronunciation
The score compares the speech-recognition transcript with the target sentence through:
- target-word coverage
- word-sequence edit distance
- missing and extra word detection

It is transcript-based feedback, not a phoneme-level accent diagnosis.

## Writing
The handwriting canvas stores stroke count, prompt and the learner's self-score. Automatic handwriting recognition or handwriting-quality grading is not claimed.
