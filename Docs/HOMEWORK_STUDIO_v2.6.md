# Homework Studio v2.6

Supported writing structures:
- sentence
- paragraph
- formal letter/application
- notice
- report
- composition-ready template architecture

The learner fills guided fields. The engine assembles the structure, checks required fields, opening capital, ending punctuation and minimum detail rules, then provides a checklist.

Drafts are stored in SQLite. A draft can be copied or exported as a text file through the device save dialog.

Homework Studio supports the learner's own writing. It is not an unrestricted answer generator that silently completes all schoolwork for the child.
