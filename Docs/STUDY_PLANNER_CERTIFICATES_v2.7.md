# Study Planner and Certificate Studio v2.7

## Weekly Study Planner

The planner can:
- generate a seven-day plan from saved learning analytics
- prioritise a weak skill
- include pronunciation, lesson, conversation, exam, story and review tasks
- add custom tasks
- select a linked app module
- set planned date and duration
- mark complete
- award a small first-completion reward
- delete tasks by swiping

The current planner is offline. Device notifications and alarms are not yet included.

## Certificate Studio

Certificates unlock from:
- XP
- successful pronunciation exercises
- passed mock exams
- completed study tasks

Unlocked certificates can be exported as printable A4 landscape HTML. They are Mewtionary learning-achievement documents, not school-board or government academic certificates.
