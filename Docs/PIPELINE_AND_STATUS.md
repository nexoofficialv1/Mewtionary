# v2.0 Development Pipeline

## Phase A — Foundation included in this package
- Unity runtime project
- Procedural 3D teacher blockout
- Classroom bootstrap
- articulated head/arms/legs
- breathing and blinking
- eye-follow
- seven viseme mouths
- touch reactions
- book/pointer/chalk states
- Flutter-to-Unity JSON command contract
- Blender blockout and armature generator

## Phase B — Professional character
1. Character concept turnaround: front / side / back
2. 3D sculpt and retopology
3. UV and toon textures
4. full humanoid rig
5. facial blendshapes
6. animation polishing
7. export FBX/GLB
8. drop into the existing Unity controller

## Phase C — Learning integration
- Dictionary pronunciation
- Story narration
- Board explanation
- child voice listening
- praise/correction
- repeat-after-child
- class-wise lesson gestures
