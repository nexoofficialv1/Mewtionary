# Learning Games v2.5

Included game engines:

1. Word Match  
   The learner chooses the correct English–Bangla meaning.

2. Spelling Builder  
   The learner taps letter tokens in the correct order.

3. Sentence Builder  
   The learner arranges word tokens to form a correct sentence.

Each challenge records correctness and attempts. Correct first completion may award XP and coins. Teacher feedback provides praise or a stored hint.
