# Mewtionary 3D Teacher v2.1 Unity Project

## Foundation demo
Menu:

```text
Mewtionary → Build 3D Teacher Prototype Scene
```

## v2.1 lesson scene
Menu:

```text
Mewtionary → Build v2.1 Lesson Integration Scene
```

Press Play. The procedural teacher is created automatically.

## Install a final professional character
Menu:

```text
Mewtionary → Final Character Setup Wizard
```

Select the imported FBX/GLB prefab, analyse it, then create the production profile and runtime prefab.

## Validate Android setup
Menu:

```text
Mewtionary → Validate Android Teacher Build
```

## Runtime command target
```text
GameObject: MewtionaryTeacher
Method: ReceiveCommand
Payload: JSON
```

The lesson and Flutter APIs do not need to change when the blockout is replaced by the final model.
