# Mewtionary v2.8 — Flutter-Only Learning App

Mewtionary is an offline-first English–Bangla dictionary and learning
application for early learners through Class 9.

Version 2.8 removes the animated/3D guide and all Unity dependencies.
The Android app is built entirely with Flutter. Text-to-speech remains
available only as explicit audio feedback inside learning activities.

## Main modules

- Offline English–Bangla dictionary and data-pack importer
- Class-wise learning paths
- Grammar, tense, reading and writing
- Pronunciation and listening practice
- Conversation Lab and Homework Studio
- Smart Revision and Mock Exam Centre
- Weekly Study Planner
- Parent controls, analytics and reports
- Rewards and printable learning certificates

## Build

Run the GitHub Actions workflow: **Build Mewtionary Flutter-Only APK**.
Unity Editor, Unity Cloud and a Unity licence are not required.
